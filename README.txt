Leah & Lena's NZ Math Adventure (version 11)

Upload all files in this folder to the ROOT of a GitHub repository, turn on GitHub Pages
(Settings > Pages > Deploy from a branch > main > / (root)), then open the Pages link on each device.

Optional pictures: create a folder named img and add files named exactly as listed in the prompt pack
(for example img/hero_royal.webp or img/ic_num_kpop.png). The app uses them automatically when present.
